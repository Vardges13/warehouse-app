# Складской ассистент

Высокоточный ассистент по складской логистике и подготовке отгрузочных документов.

## 🚀 Быстрый запуск

### 1. Установите Google Gemini API ключ

Получите ключ на: https://makersuite.google.com/app/apikey

```bash
# Создайте .env файл
cp .env.example .env

# Отредактируйте .env и вставьте ваш API ключ
nano .env
```

### 2. Запустите приложение

```bash
bash start.sh
```

Откройте в браузере: http://localhost:8090

## 📋 Функциональность

### Входные данные
1. **Спецификация** — Excel файл со списком изделий
2. **Шаблон накладной** — пустой бланк накладной Excel
3. **Фотографии маркировок** — по 1 фото на каждое изделие

### Алгоритм работы
1. **Проверка файлов** — все 3 типа загружены
2. **Анализ качества фото** — выявление нечитаемых изображений
3. **Извлечение маркировок** — через Gemini Vision API
4. **Двойной пересчёт** — верификация количества
5. **Сопоставление** — сравнение с спецификацией
6. **Финальные параметры** — тип отгрузки и дата
7. **Генерация документов** — заполненная накладная + обновленная спецификация

### Выходные файлы
- `Накладная_заполненная.xlsx` — готовая к печати накладная
- `Спецификация_обновленная.xlsx` — обновленная спецификация с отметками

## 🛠 Технические характеристики

- **Backend:** FastAPI + Python 3
- **Frontend:** HTML5 + Tailwind CSS + Vanilla JS
- **Excel:** openpyxl
- **Vision AI:** Gemini 2.0 Flash
- **Порт:** 8090

## 🆘 Устранение проблем

### Ошибка установки python-magic
```bash
# macOS
brew install libmagic

# Ubuntu/Debian  
sudo apt-get install libmagic1

# CentOS/RHEL
sudo yum install file-libs
```

### Порт 8090 занят
Измените порт в последней строке `start.sh`:
```bash
uvicorn app:app --host 0.0.0.0 --port 8091 --reload
```

### Ошибки Gemini API
- Проверьте интернет-соединение
- Проверьте, что переменная `GEMINI_API_KEY` задана в файле `.env`.
